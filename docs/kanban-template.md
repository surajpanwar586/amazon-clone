# Kanban Board Template

This template provides a basic structure for a Kanban board with three columns: To Do, In Progress, and Done.

## To Do

This column contains tasks that are planned but not yet started.

**Sample Cards:**

*   **Task:** Set up user authentication
    **Description:** Implement user registration and login functionality.
    **Acceptance Criteria:**
    *   Users can create a new account.
    *   Users can log in with their credentials.
    *   Users receive a JWT token upon login.

*   **Task:** Design the product page UI
    **Description:** Create the UI mockups for the product details page.
    **Acceptance Criteria:**
    *   Mockups for desktop and mobile views are created.
    *   All necessary UI elements are included (product image, price, description, add to cart button).

## In Progress

This column contains tasks that are actively being worked on.

**Sample Cards:**

*   **Task:** Implement the navigation bar
    **Description:** Create the main navigation component for the website.
    **Acceptance Criteria:**
    *   The navigation bar is responsive.
    *   It includes links to the homepage, product categories, and user profile.

## Done

This column contains tasks that have been completed.

**Sample Cards:**

*   **Task:** Set up the initial project structure
    **Description:** Create the initial folder structure for the frontend and backend.
    **Acceptance Criteria:**
    *   The monorepo is set up with a root `package.json`.
    *   Frontend and backend have their own `package.json` files.
